🌐 Página Web ARK: Survival Evolved

Este proyecto es una página web sencilla con diseño atractivo y funcionalidades interactivas usando HTML. Está inspirada en el videojuego ARK: Survival Evolved.

📸 Vista previa

Incluye títulos, secciones, fondo personalizado, interacciones con el usuario y un cambio de tema claro/oscuro.

🧰 Tecnologías utilizadas

- HTML
- Git & GitHub
